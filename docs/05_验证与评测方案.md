# 05 · 验证与评测（2026-09-27）

## 证据层次

1. 自动化回归：当前 218 项后端测试，验证权限、时限、状态、引用、快照、幂等、版本、恢复等程序约束。测试通过不是临床正确率。
2. 合成开发对照：当前协议在 40 条既有开发情境和 20 条压力语句上运行；保留所有失败。旧情境的当前疼痛与新版过去七天指标含义不同，不能暗中替换标签求高分。
3. 中文最小差异集：24 句/12 对，自编开发数据，主题包括主体、转述、发生/报告、持续/结束、条件句与否认。尚无独立临床标注。比较 no_context、all、action_sensitive 对同一实际模型候选的投影和候选追问。
4. 真人模拟使用、医生独立判读、工作量和付费验证：目前待做。

每份新报告绑定代码、数据、协议、运行器哈希、模型、时间、计划分母、错误与延迟。配对重放不计作独立推理。使用 real 模式时禁用自动词表兜底。封存 72 句留出集本轮未查看、未运行。
