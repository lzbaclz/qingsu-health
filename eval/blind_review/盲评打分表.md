# 医生盲评打分表（三组对照）

材料由 `python eval/blind_review/prepare.py` 生成：每个病例三份摘要（随机编号，评审不知来源），答案在 `answer_key.json`，评审看不到。
三组：A 表单 + 人工整理（只有问答，无自由文本抽取）；B 同一模型的普通摘要（原话直接写成摘要，无事实状态/证据/验收）；C 完整产品。

| 病例 | 摘要编号 | 完整性 1–5 | 错误数（编造/错值） | "未问写成没有"次数 | 需要修改的地方数 | 阅读+纠错用时(秒) | 能否追溯到原话 1–5 | 我会把它放进病历吗 1–5 | 备注 |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | |

规则：
- 同一病例的三份连续评，顺序随机；不要回头改分。
- "错误"只算与原始材料不符的内容；措辞风格不算错。
- 用时用手机秒表，从打开到写完备注。
- 评审人：至少 2 位（临床队友 + 独立复核者），分歧记录，不合并。
