# 06 · 数据与临床责任边界（2026-09-27）

当前为合成数据工程演示，所有协议与临床提示仍待真人审核。名称叫“辅助表达”不能自动确定监管分类；应按最终功能、用途、输出和部署方式由有资质的机构评估。本文件不作具体法律或医疗器械分类结论。

真实使用之前，需要实际机构明确服务对象、知情说明、责任人、服务时段、紧急转介、数据控制者、处理目的与保存政策，以及模型/云/消息供应商的数据条款。外部模型和跨境传输须单独审查；本机运行也不等于已完成合规。

当前技术措施包括医护角色与机构隔离、患者单次邀请、会话到期与撤销、HttpOnly cookie、来源检查、协议快照、版本审计、生产草案门禁。它们是工程措施，不代表真人资质或授权已取得。

模型抽取、事件解释与复述比较均可错。患者确认的是表达，医护复核的是被核对内容；系统不自动认定疗效、真实理解或实际执行。引用存在不证明解释正确。新的身体变化走独立症状采集；复述和生活目标备注不触发即时医学判断。

红旗联系失败必须保留后续责任。默认未配置真实外部触达通道，不能承诺门诊会自动收到消息或及时响应。

SQLite 和导出文件默认不加密。文件权限不能替代磁盘加密、备份加密、密钥管理和最小授权。删除当前数据库不删除历史备份、外发副本或机构其他系统数据。具体维护见 docs/23。
