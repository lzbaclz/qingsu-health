# 12 · 受监督影子验证方案（草案，供合作门诊与伦理 / 机构审查使用）

> 状态：**草案**，由工程起草、待临床负责人与合作机构修改。影子验证不改变任何诊疗：患者照常就诊，医生照常问诊，系统产出的摘要只用于事后比较。
> 前提（缺一不可）：机构书面授权 · 必要的伦理 / 合规判断 · 协议状态为 clinically_reviewed · 第二位临床复核者到位 · 部署安全清单中"首次试点前"各项完成（docs/06）。

## 1. 目的
在真实门诊流程中，比较"患者就诊前用体迹 AI 自述 → 系统摘要"与"医生当面问诊记录"的一致程度，回答三个问题：
1. **信息质量**：关键事实的完整率、编造率、"未问写成否认"率，与医生记录相比如何？
2. **安全**：医生当面识别出的需要当日或紧急处理的情况，系统是否都提示了？（漏升级为不可接受）
3. **负担**：患者完成用时、放弃率；医生阅读摘要用时（不要求医生据此改变任何决定）。

## 2. 设计
- 单中心、前瞻性、观察性；**系统输出不进入诊疗决策**，医生在问诊结束、写完病历后才看系统摘要。
- 规模（资源规划，非统计样本量）：30–50 例连续就诊的成年腰背痛初诊或复诊患者。
- 纳入：≥18 岁、本次主诉腰背痛、能自行使用手机、签署知情同意。排除：协议排除项（docs/04 scope）、急诊 / 重大外伤、无法自行作答。
- 流程：候诊时扫码填写（约 5 分钟）→ 正常就诊 → 医生写完病历后，独立填写"医生参照表"（关键事实清单，与协议 evaluation.critical_facts 一致）→ 事后由第二位临床人员比较系统摘要与医生参照表。
- 紧急提示：若系统在候诊时显示紧急提示，护士**立即**按门诊常规处理（这是安全保障，不是研究干预），并记录。

## 3. 指标
| 指标 | 定义 | 目标（内部，非监管标准） |
|---|---|---|
| 关键事实完整率 | 医生参照表中已明确的关键事实，系统也明确且一致的比例 | ≥ 90% |
| 编造率 | 系统记录为"有"、医生参照表为"无 / 未提及"且患者原话不支持的比例 | 越低越好，逐例复核 |
| 漏升级 | 医生判断需当日 / 紧急处理而系统未提示的例数 | 0 |
| 不必要提示 | 系统提示但医生判断无需处理的例数 | 报告，不设门槛 |
| 完成率 / 用时 | 开始后完成确认的比例；中位用时 | ≥ 80%；≤ 5 分钟 |
| 医生阅读用时 | 医生读系统摘要的秒数（写完病历后） | 报告 |

## 4. 数据与隐私
- 系统只用假名编号；与真实身份的对应表由门诊保存，团队不接触。
- 模型：境内已备案模型或门诊私有化部署；不向境外发送任何患者输入。
- 保存期限：研究结束 30 天内删除系统中的原始记录，仅保留去标识的统计结果（以伦理批件为准）。
- 访问控制：医生端需登录（docs/06 清单）；审计日志开启。

## 5. 停止规则
出现 1 例漏升级（医生判断需紧急处理而系统未提示），暂停入组，复盘协议与抽取；出现系统故障导致患者看不到紧急提示，立即暂停。

## 6. 角色
| 角色 | 负责 |
|---|---|
| 临床负责人（医生队友） | 方案、协议、医生参照表、与门诊沟通 |
| 第二临床复核者 | 独立比较系统摘要与参照表，判定错误类型 |
| 工程 | 部署、培训、数据导出、统计 |
| 合作门诊 | 授权、患者招募、紧急情况的常规处理 |

## 7. 产出
一份试点报告（上表指标 + 错误案例复盘 + 协议修改清单），作为第二家门诊接入与首次付费的依据。
