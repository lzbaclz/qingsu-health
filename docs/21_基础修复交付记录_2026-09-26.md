## 已修问题与原因

| 原有现象 | 确认原因 | 已改动与当前行为 |
|---|---|---|
| 不登录可以读取就诊，任意 actor 可记为操作者 | API 未认证，直接信任请求里的姓名 | 服务端 HttpOnly 会话、角色与机构校验；操作身份取自账号。护士不能确认病历或修改随访计划 |
| A 通知可通过 B 就诊 URL 标记已理解 | 没有核对通知归属和访问主体 | 同时检查患者会话、机构、就诊和通知归属；跨患者返回拒绝 |
| 患者记录编号相当于访问凭据 | 无患者认证 | 门诊发放限时、一次性邀请；令牌摘要入库，患者会话可到期及注销；编号本身不授予访问 |
| 默认运行缺少疗程时段、恢复指标和失访配置 | 生成器与默认协议产物不同步 | 已生成 v0.2.1（仍为模拟草案）；新增就诊固定协议快照，历史流程不随同名文件变化 |
| 关闭演示接口仍可用模拟协议创建真实环境记录 | 演示接口开关不是临床门禁 | 显式 demo/production 模式，production 拒绝未批准、模拟或未完成审核的协议 |
| 没联系上、手填尝试次数即可结案 | 完成校验过弱，操作没有身份来源 | 联系结果按登录身份和时间留痕；未接通不能完成，升级后交医生且任务仍打开 |
| 创建空随访就不再提醒失访 | 只看有无子记录 | 只以有效提交的确认时间判断响应；每份随访计划幂等创建任务 |
| 当天联系配置 120 分钟，实际延至停诊 | 计算忽略分钟配置 | 取 120 分钟与当前时段停诊时间较早者 |
| 不打开页面就没有失访检查 | 扫描绑定 GET 页面请求 | 后台调度独立执行；医护列表定时刷新并在重新可见时更新 |
| queued 自动变 sent，容易被理解为已送达 | 原演示通道只改数据库状态 | 站内通知在患者取回时标为已提供；外部通知另有持久队列、回执和失败状态；通道接收不会自动完成任务 |
| 刷新待答红旗矩阵可能跳过其行；直接确认可绕过问询 | 未重建 pending grid；确认接口未检查剩余问询 | 恢复原矩阵、保留所有未答行；非紧急流程不能越过待核实问题直接提交 |
| 表单重复初始化、提交后短暂显示旧状态 | 渲染期间调用时钟、effect 重设表单、确认后未先同步状态 | 计时惰性初始化、按记录／版本重建表单、提交后刷新状态；lint 原有警告清除 |

联系记录仍是获授权医护的自报，不等于已接入电信通话证据；患者点击确认也不等于实际理解。后续计划复述模块会进一步核验表达含义。

## 使用方法

1. 项目根目录运行 make demo（或 make backend）。演示库使用 backend/.local/demo-v020.db，首次生成五条模拟就诊记录覆盖四类路径；不会清空原有 backend/tiji.db。
2. 另开终端运行 make frontend，打开患者／医护网页。
3. 医护账号 demo-doctor，随机口令在 backend/.local/demo-access.txt，文件权限 0600。该文件已加入忽略规则，不应提交或公开。
4. 登录后生成患者采集邀请；患者打开邀请、确认适用范围后填写。同一邀请只能首次使用一次。
5. 红旗任务先记录联系尝试；未接通时填写原因并升级，不能标记完成。后续有效联系后按协议写明结果、安排及必要理由。

make demo 默认为离线 mock，界面明确显示。可通过 app.demo 的 --provider 参数选择已配置的提供者，但不因此拥有该模型的最新评测证据。

- 前端：pnpm run build 成功；pnpm run lint 退出 0、零警告。
- 新增访问边界测试：真实 cookie、双患者归属、两机构隔离、护士权限、邀请使用／过期、会话注销／过期、生产草案门禁、跨站请求拒绝。
- 新增流程测试：默认 course 配置、截止时间、空随访对照、联系失败升级、医生限定结论、缺通道不伪报成功、通知幂等、三次失败停止、协议快照固定。
- 浏览器使用独立模拟库走通：医护登录 → 发邀请 → 患者身体图／原话 → 停诊后紧急提示与终止 → 确认提交 → 医护查看 → 记录未接通 → 完成禁用 → 升级后保持未完成。没有点击拨号链接，没有发送真实外部消息。
- 独立 worker 实际进程已报告 running=true、无错误；外部通道 configured=false。外部通道的成功、失败及幂等用注入传输函数测试，未接真实门诊系统。

口令存储采用 scrypt 的 N=2^14,r=8,p=5 配置；旧本地散列在成功登录后升级。[OWASP 参数依据](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)
