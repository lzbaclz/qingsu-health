## 1. 三个假设
- **H1**：身体图 + 针对性补问，比普通表单更容易得到完整、准确的信息。
- **H2**：带原始证据的摘要能减少医生净整理时间，而不增加严重错误。
- **H3**：病程状态、一键核对与任务追踪能减少遗漏和重复联系，而不是增加无用提醒。

## 2. 离线评测（已实现）
### 2.1 数据
- 场景：`eval/scenarios/dev/`（40）与 `locked/`（40），20 个病例家族，家族不跨集；同家族改写不算独立样本。
- 口语压力集：`eval/scenarios/stress/stress_v1.yaml`，20 句**协议词表之外**的口语（尿有点费劲、屁股中间木木的、差点摔了、老寒腰……）。其中 4 句来自模拟评审附录 A（曾用于制定通用规则），16 句新写且**不得**抄进提示词或词表。
- 全部由工程起草、**尚未经临床审核**；对外只能称"开发基线"。

### 2.2 两层指标
| 层 | 含义 | 代码 |
|---|---|---|
| 抽取层 | 患者原话刚被模型抽取、还没核对与问卷时的状态。衡量模型本身，也是"患者不认真核对"时的最坏情况 | X1 漏抽（问卷可兜住）· X2 编造 · X4 原话层红旗漏识别（问卷可兜住）· X8 错抽 |
| 最终记录 | 模拟一位认真、诚实的患者走完一键核对与问卷并确认之后，医生看到的记录 | E1 关键遗漏 · E2 编造 · E3 未问写成否认 · E4 漏升级 · E5 不必要升级 · E6 越界 · E7 矛盾未呈现 · E8 理解错 · E9 非关键遗漏 |
- 只评"原话抽取改变了的事实"：身体图等患者直接输入不算模型的账；场景本身设计的矛盾、带"好像"的模糊候选引发的澄清不算错抽。
- 紧急终止后没再问到的事实记为说明（S1），较低级别红旗被紧急终止覆盖记为说明（S2），不计错。
- 模拟患者在一键核对里对照自己的真实情况回答；真值没规定的条目按"对"处理并单独计数（报告里"无法判断"）。
- **第二轮评审提醒：这等于用答案核对答案。**认真患者的最终层只能证明流程能闭合，不能证明真人会抓到错抽。所以现在分三层报：
  | 层 | 怎么得到 | 说明什么 |
  |---|---|---|
  | 模型刚读完原话 | 抽取层 X 码 | 患者完全不核对时的最坏情况 |
  | 粗心患者 | `--patient careless`：一键核对一律点"对"，问卷照常 | 错抽与编造原样留下、漏抽仍由问卷兜住，更接近真实的下界 |
  | 认真患者 | 默认 `--patient attentive`：知道真值后核对 | 流程能闭合的上界 |
  真人会不会抓到错抽，看 §3 的植入错抽比例。

### 2.3 运行
```bash
make eval            # 开发集 + 锁定集，离线词表
make eval-stress     # 口语压力集，离线词表
make eval-real       # 真实模型 Claude：压力集 / 开发集 / 锁定集 + 压力集 effort=high 对照，并生成证据表（需 ANTHROPIC_API_KEY）
make eval-cn         # 国产模型（需 TIJI_COMPAT_*）
make eval-careless   # 粗心患者对照（80 场景 + 压力集）
make llm-check       # 真实模型连通性自检（跑真实评测前先跑它）
make evidence        # 汇总成 BP 第 5 页证据表 → eval/results/证据表.md
```
真实模型评测默认 4 进程并行、失败不兜底；每个场景各自记用量，主进程汇总，报告里有调用次数、token、抽取耗时 p50/p90、按公开价估算的总费用与"每次就诊"费用（汇率按 7.1 假设）。`make eval-real` 第一步是自检，自检不过就停，不浪费一整轮。

如实作答的模拟患者（`--patient truthful`）：与认真患者相同，另外脚本没写答案的题也按真值回答，用于两组对照，让"只发问卷"的一组不因脚本设定吃亏。

解读：离线词表在词表外口语上漏得多、会编造（"差点摔了"→外伤），但**漏抽被问卷兜住、错抽要靠患者在一键核对里点"不对"**：认真患者时最终记录没有关键错误，粗心患者时 20 句里有 3 句留下关键错误。所以一键核对是否有效，最终要看真人（§3）。离线词表曾按压力集发现的问题修过（eval/CHANGELOG.md），这些数字是事后的，只作兜底基线；对外的模型能力数字必须来自真实模型（§2.3）。

### 2.5 门槛（内部产品决策，非监管标准）
锁定集 **零** E2 编造、零 E3 未问写成否认、零 E4 漏升级、零 E6 越界；关键事实完整率 ≥95%。真实模型的抽取层 X2 / X8 要单独报告，不能被最终层的兜底掩盖。

### 2.6 场景审核
每条场景的 `ground_truth` 由临床人员审核（`review.clinical_reviewed_by`），红旗与矛盾类由第二位临床人员独立复核，分歧记录在 `eval/scenarios/INDEX.md`。锁定集在调试中被查看过（`eval/CHANGELOG.md`），审核改写后才算真正锁定。

## 3. 真实人的模拟交互（工具已就绪）
- 本轮 **10 名非团队成员**，每人 2 张卡（P01–P05：A→C；P06–P10：C→B）；卡 D 与另外 10 人留到决赛前。
- 主持人打开 `/p?code=UT-P03-C` 即可；每一步耗时自动记录（不记录输入内容）；主持人只手工记录"复述下一步"与主观负担。
- `make user-test-report` 生成汇总；指标：完成率 ≥80%、用时中位数 ≤4 分钟、复述下一步 ≥90%、卡 C 看到并理解紧急提示（必须报告）、**植入错抽被点"不对"的比例**（必须报告）。
- **植入错抽**（第二轮评审新增）：用 `make user-test-backend` 启动，卡 A 植入"疼痛串到臀部或腿：有"，卡 B 植入"开始多久：3 天以内"，引文取自参与者自己的原话，之后的核对、问卷、摘要与真实错抽完全一样；每次植入记审计，测试后当场向参与者说明。P01–P10 每人正好遇到一次。这是回答"真实患者会不会一路点'对'"的唯一证据。
- 对照阅读：*Reliability of LLMs as medical assistants for the general public*（Nature Medicine 2026）——模型答对 ≠ 用户做对。

### 3.1 植入错抽的两种难度（第三轮评审 §2.1 Q4）
- 卡 A · 显眼型：放"疼痛串到腿：有"，引文多半是"腿没有麻"，错误值旁边就是反驳它的原话，测的是抓错率的**上限**。
- 卡 B · 隐蔽型：卡片写了"去年也闪过一次腰"，系统放"这次开始多久：超过 3 个月"，引文取这句，看起来支持错误值，与压力集里真实错抽"腰疼老毛病了"同型。参与者没提去年那次时退回显眼型，按实际类型统计。
- 汇总分类型报"点不对"的比例并给 Wilson 95% 区间；每种约 5 例，只能说明有没有明显问题，不能说成总体比例。
- 可用性测试后端默认用离线词表，参与者打的字不出本机；换模型用 `make user-test-backend UT_PROVIDER=compat`，用境外模型须先在参与者说明里写明。

## 4. 三组对照与盲评（决赛前）
| 组 | 内容 | 回答的问题 |
|---|---|---|
| A 表单 + 人工整理 | 只有问答，无原话抽取 | 简单方法已解决多少 |
| B 同一模型的普通摘要 | 原话直接写成摘要，无事实状态/证据/核对 | 我们是否只是包装了提示词 |
| C 完整产品 | 本系统 | 事实状态、证据、核对、任务是否带来额外价值 |
- `eval/blind_review/prepare.py` 生成盲评材料（随机编号、答案另存）；至少 2 位评审，分歧不合并；用时包含纠错。
- 离线消融：`--arm form_only`（不抽取原话）已实现。

## 5. 二维 vs 三维
首版只做标准 2D 前/后视图。3D 只有在同样任务下证明定位一致性更高或用时更短时才投入。

## 6. 阶段目标（内部拟议，非已达成）
| 指标 | 目标 |
|---|---|
| 模拟任务完成率 | ≥80% |
| 典型采集用时 | 中位数 ≤4 分钟 |
| 关键事实完整率 | ≥95%（必须报告分母与未知） |
| 严重编造 / 关键遗漏 / 越界 | 锁定集为 0 |
| 医生净整理与纠错时间 | 中位数减少 ≥20% |
| 下一步理解 | ≥90% |
| 工作流故障 | 不丢失已确认信息；发送失败不标已处理 |
| 商业验证 | 90 天内至少一家独立机构付费并持续使用 |

## 7. 真实患者之前的门槛
机构授权 + 必要的伦理/合规判断 + 协议 clinically_reviewed/approved + 独立复核 → 才能做 30–50 个就诊流程的**受监督影子验证**（不改变诊疗，方案见 docs/12）。之后再考虑两家机构 80–120 个流程的可行性试点。这些数字是资源规划，不是统计学样本量。
