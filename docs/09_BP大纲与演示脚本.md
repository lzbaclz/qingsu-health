# 09 · BP 与演示入口

当前可用文案为 [BP 1.3 与三分钟脚本](11_BP逐页文案与视频脚本.md)。本地 HTML 在 [bp_slides/index.html](bp_slides/index.html)。历史线上 artifact 未更新，不再作为当前交付。

路演只讲一个主线：在两次就诊之间核实真正的变化，减少解释不清引起的额外工作。以“今天才提起去年腿麻”开场，让评委看到报告时间不等于起病时间。随后展示一条需要澄清的分支、原话依据，以及计划第几版的复述差异。

演示必须使用模拟编号，披露默认词表或本机模型及实际耗时。模型成绩、流程成绩、真人结果分别陈述。联系方式为模拟占位，不拨打外部电话。

评委问创新：承认预问诊、引用、连续管理均有成熟先例，自己的增量是可核验的语境与处理差异假设，当前方法尚未建立领先性。

评委问实用：展示总工作量的验证设计与真实试用证据（如尚无则说尚无），不要用 218 项软件测试代替价值验证。

评委问商业：拟售给持证小型肌骨康复门诊，价格与交付成本尚待访谈验证，奖项奖金不计运营收入。
