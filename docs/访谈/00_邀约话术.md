# 门诊访谈 · 邀约话术（医生牵头发出，工程陪同记录）

## 微信 / 短信（约 150 字）
> 王主任您好，我是 XX 医院 XX 科的 XX。我和一位工程师在做一个帮门诊整理患者就诊前、随访中症状描述的工具，想向您请教 30–40 分钟：贵科现在随访和就诊前沟通是怎么做的、哪里最花时间。**不涉及任何患者信息，也不需要您用任何产品**，纯粹了解真实流程。您这周或下周哪天方便？线上线下都可以。谢谢！

## 电话开场（30 秒）
> "我们在做一个很小的工具，想先搞清楚门诊里真实的做法，避免闭门造车。今天只想听您讲最近一次真实的随访或就诊前沟通是怎么进行的，我们不推销、不录患者信息。"

## 注意
- 目标 2 家：一家与医生队友**无隶属关系**的门诊优先（商业证据要"无创始关系"）。
- 不要带着"AI 很厉害"去，带着"想学习你们怎么做"去。
- 访谈前把 `01_访谈提纲.md` 发给对方可以，但不要发产品演示——先听，最后 5 分钟再展示。
