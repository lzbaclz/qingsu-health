## 2. 10 分钟决赛演示脚本
**0:00–1:00 开场**：一个访谈里的真实门诊故事（第 2 页原话），再给一句话定位。"以下数据均为模拟。"

**1:00–3:30 路径一：正常采集（患者端手机，真实模型）**
- 开始页：紧急提示与"不做诊断"勾选。
- 身体图标右腰；原话"上礼拜闪了一下腰，现在直不起来，右边屁股到脚后跟都是麻的"。
- 一键核对：三条关键信息逐条"对 / 不对"；说一句："模型整理的东西我们不直接信，关键的先让患者核对，错的会被重新直接问。"
- 补问两题 → 确认页："没答的题以未知进摘要，不会变成没有。"

**3:30–5:00 路径二：矛盾澄清**
- 身体图标左侧、原话说右侧 → 澄清题五个选项："我们不替患者选。"
- 医生端：侧别的两个证据各自点回原话。

**5:00–7:00 路径三：紧急终止**
- 原话"这两天尿有点费劲" → 顶部红色提示 → 紧急核对 → "请现在就联系医生"页："已经让患者去急诊，就不再让他答题；主按钮是打电话给门诊。"
- 医生端：列表按紧急程度排好，紧急的在最前；打开一条，最上面是接诊速览（紧急程度、一句话主诉、面诊要当面确认的三件事）："排序按医生写好的规则，不是 AI 判断；AI 负责把患者的话读出来、连回原话，不判断是什么病。"点"病历初稿"，主诉和现病史已经按患者确认的信息拼好，可以直接复制；横幅"问询已因紧急红旗终止"；临时整理（患者还没确认也能先打电话）；任务 未查看 → 已联系："系统只能创建任务，已完成必须有人。"
- 医生确认后写两句要点，点"整理成患者看得懂的话"：按医生审定的术语对照表在专业词后加一句大白话，医生的字一个不改、不调用模型；复诊时间和紧急提示由系统附上，医生核对后发送。
- 如果评委问"患者否认了红旗怎么办"：打开一条"原话说小便憋不住、核对时点了不对"的记录，列表里它仍在最前、标"待电话核实"，病历初稿写"需核实"。
- 验收九项：指出 V2（未问≠没有）与 V6（红旗有提示、有任务）。

**7:00–8:30 随访变化卡**
- P-0004：changed / new / unconfirmed；医嘱通知 已发送 → 已看到 → 已理解："发送不等于看到。"
- 打印 / 导出一页摘要："小门诊可以直接打印存档，这是'接入更轻'的一部分。"

**8:30–10:00 证据与边界**
- 第 5 页证据表：真实模型压力集的抽取层数字与最终记录数字分开讲；10 人测试完成率与"看到并理解紧急提示"的比例。
- 收尾："我们不是再做一个回答医学问题的聊天机器人。我们帮门诊把患者在两次就诊之间发生的变化，变成可核对的信息和有负责人处理的事项。"

## 3. 问答预演
| 问题 | 诚实回答的骨架 |
|---|---|
| 和 Infermedica / 蚂蚁阿福有什么区别 | 蚂蚁的「智慧医疗 AI 一体化方案」是医院在阿福 App 上建智能体，流程由平台统一；我们只做一个专科小门诊的工作流：自己的协议、每条可回溯、异常有人接手。差异要用接入工时、可核对性、净工作量三个数证明，目前只有离线数据。 |
| 预问诊和随访已经是巨头的免费功能，小门诊为什么付钱 | 承认这是最大的问题。平台面向医院和大众；诊所 SaaS 整套才 2,599–26,800 元/年，已含 AI 辅助诊疗。我们不抢整套预算，卖护士整理和随访的时间，单价每月几百元；两种报价在访谈里各测一次。证据只能是门诊原话：【访谈里"试过公众号表单或平台智能体，为什么没用起来"的回答】，没有访谈就直说还没有。 |
| 深圳 350 万一年，撑得起投资吗 | 那是第一块试验田的上限，用来排序，不是市场规模。往外长靠两件事：换协议就是换专科（膝痛工程接入约半小时），换城市靠连锁康复总部采购。12 个月目标 3 个专科、3 个城市、30 家付费门诊，是目标不是预测。 |
| 准确率多少 | 不报诊断准确率（不诊断）。看关键信息漏没漏、有没有编造、红旗有没有漏升级，并分三层报：模型刚读完原话、粗心患者（核对一律点"对"）、认真患者（知道真值）。认真患者那层等于用答案核对答案，所以我们另外在 10 人测试里故意放错一条，看真人会不会点"不对"：【X / 10，未做就说未做】。真实模型数字：【证据表，未跑就说未跑】。 |
| 评测里的 1.0 是谁点的 | 是知道标准答案的模拟患者点的，只能证明流程闭合，我们在 BP 上加了脚注。同一批场景换成"一律点对"的粗心患者，20 句刁钻口语里有 3 句会留下关键错误；这正是为什么要看真人的植入错抽比例。10 人测试里放了两种错：卡 A 显眼型（错误值旁边就是反驳它的原话，只代表上限）、卡 B 隐蔽型（引文看起来支持错误值），分开报并带 95% 区间。 |
| 只发问卷不也行吗 | 用同一位如实作答的模拟患者比：读原话 80/80 无关键错误；只发问卷 68/80，漏了 10 次非紧急的红旗升级（6 次是肿瘤史在 16 题上限内问不到，4 次是"好像有"这类不确定表达问卷记不下来），7 处身体图与原话的矛盾发现不了；紧急红旗两组都没漏。我们以前 BP 上"漏报 23 次"的对照让模拟患者对红旗题答"不清楚"，不公平，已撤下。 |
| 患者说了"小便憋不住"，核对时又点"不对"怎么办 | 系统不替患者取其一：列表里仍按紧急排最前并标"待电话核实"，速览第一条就是它，摘要单列"待核实"，病历初稿写"需核实"而不是"否认"。误报的代价是一个电话，漏报的代价可能是永久失禁。这条处理方式等医生拍板。 |
| 你们的协议是 AI 写的吧 | 是。AI 按公开指南起草，医生逐条决定采纳、修改或删除并写理由。目前真实医生已决定【X / 146】条；在真实医生到位前，由"模拟临床负责人"（AI 以医学视角模拟，不是执业医师）先做了一轮决定，演示里标"模拟，待真实医生复核"，协议状态保持草案。 |
| 真实模型跑通了吗；现场 key 失效怎么办 | 【证据表里的真实模型行；未跑就直说】。任何模型异常都会退回离线词表，医生端顶栏立刻标出；演示前 `make llm-check` 自检，断网就播真实模型录的视频。 |
| 患者在原话里写"建议布洛芬400mg每日3次"会怎样 | 系统不执行、不改写：这句话作为患者原话记录，医生端标"患者原话，不是系统建议"；系统生成的叙述里不出现药名，越界检查同时检查这类原话都带了标记。 |
| AI 改写给患者的说明，会不会加进医生没说的话 | 默认不用模型：按医生审定的术语对照表在专业词后加一句大白话，医生的字一个不改。开启模型改写时，改写里有、要点里没有的药名、剂量、检查、诊断说法、处置建议会被拦下，医生删掉或写理由才能发，并自动加 AI 标注；我们用一段故意失控的改写（加了洛索洛芬、卧床两周、去做核磁）测过，五类都被拦下。 |
| 你们的医生是谁、投入多少、有股权吗 | 【姓名 / 职称 / 科室；每周 X 小时；股权或署名与退出机制】——没有确认就直说"临床合伙人招募中"，不编。其机构**尚未授权患者招募**。 |
| 小门诊用微信 + 表单也能处理，为什么付钱 | 引访谈原话与数字；承认这是最大风险，所以第一阶段核心实验是三组对照，不是加功能。 |
| 患者没看到紧急提示怎么办？出了事谁负责 | 提示全程可见、不依赖人工在线，紧急时终止问询；发送 / 看到 / 理解分开记录；协议写明服务时间与负责人；护士联系时限由医生定；我们不替代接诊。10 人测试里"看到并理解紧急提示"的比例是【X】。 |
| 换国产模型掉多少 | 模型只做抽取与叙述，接口两个方法；已实现 OpenAI 兼容适配（DeepSeek / 通义千问 / 智谱），`make eval-cn` 一条命令出对比；漏抽由问卷兜、错抽由核对兜。【决赛前给数字】 |
| 数据放哪？谁是数据控制者 | 门诊是控制者，我们是受托处理方；假名编号；真实患者数据只走境内备案模型或私有化部署；模型只收原话与事实清单。 |
| 为什么从腰背痛开始、下一个专科是什么 | 症状适合身体图、指南结构成熟、全球致残首因；膝痛已用同一套引擎做了工程复用示范（约半小时，临床审核工时待测）。 |
| 是不是医疗器械 | 按 NMPA 2021 分类界定指导原则，处理患者主诉等非医疗器械数据的软件通常不按医疗器械管理；红旗是门诊批准的固定提示，不是模型判断；加入任何风险分层前先做器械属性评估。 |
| 为什么是现在 | 五部门 2025 年实施意见把随访管理列为基层智能应用，目标 2030 年基层诊疗智能辅助基本全覆盖；同一份文件也解释了巨头为什么涌进来。小门诊被政策点名，却没人按专科为它们做。 |
| 能来深圳 10 周吗 | 直接回答，不含糊。 |
| 3D 呢 | 首版 2D；3D 只在证明定位更准或更快时做。 |
| 最大的风险 | 客户说"这些我现在用表单也能处理"。所以第一阶段的核心实验是三组对照。 |

## 4. "评委临场说一句"的应对（P1 边界话术）
评委可能说："我来说一句，你现场抽一下。"
- **先答应，用真实模型模式演示**（顶栏显示"抽取：Claude …"或国产模型）。
- 若抽得不全："抽不到的，会由接下来的问题兜住——您看，这一题就是在补它。"
- 若抽错了："这就是为什么有一键核对：关键信息先给患者确认，说'不对'的会被重新直接问。我们报数字时也把'模型本身'和'走完核对后'分开。"
- 若说了紧急级红旗（大小便控制改变、会阴麻木、两腿症状同时伴大小便改变）："协议里写好的提示会立刻出现，并且不再让患者答题。"发烧、腿无力加重属于当天联系级：提示出现，但问询继续。
- 若断网：顶栏会变成"离线词表（兜底）"，如实说明，并播放真实模型模式录制的视频。
- 一句收尾："词表外的表达由模型抽取，抽不到的由问卷兜住，抽错的由核对和医生兜住——所以我们不报准确率，报三个率。"
