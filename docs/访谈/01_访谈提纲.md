# 门诊访谈提纲（半结构化，30–40 分钟）

目标：拿到 BP 第 2 页需要的三样东西——**一个真实故事、三个数字、谁能拍板买**。
原则：问"最近一次具体发生了什么"，不问"你觉得 AI 有没有用"。

## 0. 开场（2 分钟）
- 说明目的、不涉及患者信息、可以随时停；征得同意后可记笔记（不录音，除非对方主动同意）。

## 1. 最近一次真实的随访 / 就诊前沟通（15 分钟）——最重要
1. "请您回想**最近一次**腰背痛（或本科常见问题）患者的随访/就诊前沟通，从患者联系你们开始讲。"
   - 追问：通过什么渠道（电话/微信/公众号/纸质表）？谁接？几点？
2. "患者说的情况是谁整理给医生的？整理成什么样子？"
   - 追问：**这一例大概花了几分钟**？（数字 ①）
3. "医生看诊时还需要重新问哪些？为什么？"
4. "有没有出现过信息漏了或者说错了，后来才发现的情况？最近一次是什么时候、怎么补救的？"（数字 ③：最近一次遗漏）
5. "什么情况会让你们马上让患者来/去急诊？这个判断是谁做的？有没有书面清单？"

## 2. 频率与负担（8 分钟）
6. "一周大概有多少例需要这样整理或随访？"
7. "每周因为信息不全要**再联系患者**几次？"（数字 ②）
8. "这些工作占护士/助理多少时间？他们最烦哪一步？"

## 3. 现有工具（5 分钟）
9. "现在用什么记（表格、HIS 备注、微信截图）？为什么没用专门的系统？"
10. "试过什么工具没坚持下来？卡在哪？"

## 4. 采购（5 分钟）
11. "如果有个工具能让患者提前把情况说清楚、异常有人接手、医生看摘要能点回原话——**谁能决定用？预算怎么批？**"
12. "你们愿意用什么证据来判断它有没有用？（比如试用两周，比较整理时间）"
13. "愿不愿意做一个**两周的非约束性试用**？前提是不接触真实患者数据，先用模拟病例或脱敏记录。"（→ 意向书模板）

## 5. 收尾（3 分钟）
- 最后 3 分钟演示 P-0002（矛盾澄清）或 P-0003（紧急终止）一条路径，只看反应，不追问买不买。
- 问："还有谁我们应该去聊？"

## 必须带回来的
| 项目 | 例子 |
|---|---|
| 一个故事（可脱敏后引用） | "上个月有个患者说腰疼，护士记成右边，医生看诊才发现是左腿麻……" |
| 数字 ① 每例整理用时 | 约 X 分钟 |
| 数字 ② 每周补联系次数 | 约 X 次 |
| 数字 ③ 最近一次遗漏 | 时间 + 后果 + 怎么补救 |
| 谁拍板、预算量级 | 科主任 / 院长；月度 X 元以内可直接批 |
| 试用意向 | 愿意 / 需要再看 / 不愿意 + 原因 |
