# 08 · 真实临床协作任务

用户已确认许青冬为临床协作者：青大医附院临床专业研究生毕业，目前在省三甲医院从事移植相关工作。具体审核职责、执业资格、肌骨领域复核及机构批准尚未提供。AI 模拟决定不计临床审核。

请由实际参与者决定：适用范围和纳入/排除；逐条红旗提示、停止问询和不确定性处理；服务窗口与联系失败责任；事件主体/时间核实措辞；版本化计划的复述要点与复核方法；生活目标记录是否适合该人群。默认协议 0.2.6 不能直接批准为临床正确。

先由临床负责人给出独立决定，再由另一名真实人员复核。记录姓名/资格/机构/职责、审核日期、修改依据和未决问题，避免只把模拟表格改成“已审核”。工程师负责实现和可复现回归，医生负责临床决定，机构负责实际服务和数据授权。

对开发集的错误逐项判断：是语言理解错、语境缺失、协议不适合、标签旧了，还是安全提醒过多。不要把所有失败都用“保守安全”解释。

初期验证可用合成情境和成人角色扮演，先测工作量与交流质量。真实患者招募、临床使用、法律与伦理条件须由实际机构落实。本项目不会代签、联系或招募。
